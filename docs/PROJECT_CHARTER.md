# Project Charter

## Purpose

C.V.A.delivery is the canonical operating repository for building a profitable ecommerce business around a Germany-based TikTok creator.

The project combines:
- TikTok content and affiliate testing
- TikTok Shop where eligible
- Shopify
- dropshipping
- supplier validation
- product economics
- compliance
- data-driven scale decisions
- later private-label / brand development

## North star

Select few products with credible profit potential rather than building a large undifferentiated catalog.

Every candidate must answer:

> Why would someone buy this product now?

If the answer is weak, the product does not enter the top catalog.

## Ownership boundary

The creator/client is the sole business owner.

Marian assists without charging a fee and is not to be treated as the owner of the business. External accounts must be created under the owner's identity and dedicated business email.

## Decision pipeline

RESEARCH
→ SCORE
→ SUPPLIER CHECK
→ COMPLIANCE CHECK
→ UNIT ECONOMICS
→ CONTENT TEST
→ AFFILIATE TEST
→ CLICK DATA
→ ORDER DATA
→ PROFIT DATA
→ SCALE / TEST MORE / HOLD / KILL

## Non-negotiable rules

1. No large inventory purchase before validation.
2. Gross margin is not treated as net profit.
3. Unknown data stays unknown; do not invent it.
4. High score does not override compliance failure.
5. Every score carries an evidence confidence level.
6. Products with insufficient evidence remain NEVALIDATED.
7. Supplier identity, fulfilment route and landed cost must be verified before scale.
8. Real performance data replaces assumptions as soon as it exists.
