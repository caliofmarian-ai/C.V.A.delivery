# Product Scoring

## Score

Each product receives a provisional score from 0 to 100.

| Dimension | Weight |
|---|---:|
| Demand | 15% |
| TikTok potential | 20% |
| Margin | 15% |
| Purchase impulse | 10% |
| Video demonstration | 10% |
| Competition | 5% |
| Logistics | 10% |
| Return / risk | 5% |
| Scalability | 5% |
| Branding | 5% |

Weights may be changed later when real project data proves a better model.

## Classification

- 90–100: PRIORITY MAXIMUM
- 80–89: RAPID TEST
- 70–79: WATCHLIST
- 60–69: WEAK
- below 60: REJECTED

## Confidence

Score and confidence are separate.

Confidence levels:
- HIGH
- MEDIUM
- LOW

Example:

**82/100 — LOW CONFIDENCE — NEVALIDATED**

means the theoretical product profile is strong, but the evidence is incomplete.

## Hard gate

A high product score never overrides:
- prohibited product rules
- counterfeit/IP risk
- product-safety failure
- missing mandatory conformity evidence
- unacceptable logistics
- unsustainable unit economics

## Decision statuses

After testing, use:
- SCALE
- TEST MORE
- HOLD
- KILL
